# Задание 2 — Консольное приложение на Objective-C

## Описание
Консольное приложение, выводящее таблицу значений n и n² для n от 1 до 10 с заголовками колонок.

## Структура (КИС)
- `TableGenerator.h` — интерфейс класса
- `TableGenerator.m` — реализация класса
- `main.m` — создание экземпляра и вызов метода
