# Задание 7 — Обработка массивов на Swift (MVC)

## Описание
Консольное приложение для работы с массивами с архитектурой MVC. Индивидуальное задание (Вариант 1): класс DataManipulator, сортирующий опциональный массив строк по количеству гласных букв.

## Операции с массивами
- Вывод массива
- Создание пустого изменяемого массива
- Ввод элементов с консоли
- Подсчёт количества элементов
- Добавление элемента
- Вставка элемента по индексу
- Удаление последнего элемента
- Удаление элемента по индексу
- Удаление всех элементов

## Структура проекта (MVC)
- `Model/StringModel.swift` — класс DataManipulator
- `View/ConsoleView.swift` — вывод данных
- `Controller/AppController.swift` — управление логикой
- `main.swift` — точка входа
