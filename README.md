# Задание 6 — Обработка текстовых данных на Swift (словарь, SPM)

## Описание
Консольное приложение для работы со словарём. Использован Swift Package Manager для модульной структуры. Индивидуальное задание (Вариант 1): словарь с данными о человеке (Person: name, weight) и месте работы (Staff: department, position).

## Операции со словарём
- Инициализация пустого словаря
- Инициализация словаря с данными
- Ввод данных в словарь
- Подсчёт количества элементов
- Вывод значения и ключа по ключу
- Вывод всех элементов
- Добавление элемента
- Модификация элемента
- Сортировка по ключу и по значению
- Удаление одного и всех элементов

## Структура проекта (SPM)
- `Package.swift` — манифест
- `DictionaryPackage/` — библиотека (DictionaryManager)
- `DictionaryApp/` — исполняемое приложение (меню)
