# Задание 4 — Консольные приложения на Swift

## Описание
Решение квадратного уравнения ax² + bx + c = 0 (Вариант 1). Демонстрация трёх способов запуска Swift-кода.

## Способы
1. **Swift REPL** — интерактивная консоль
2. **Playground** — среда в Xcode
3. **swiftc** — компиляция в терминале

## Файлы
- `equation.swift` — код решения
- Скриншоты REPL, Playground, терминала
