# Задание 3 — Работа с массивами на Objective-C

## Описание
Консольное приложение для работы с неизменяемыми и изменяемыми массивами (NSArray, NSMutableArray). Индивидуальное задание: сортировка массива целых чисел по возрастанию, создание нового массива из первых трёх элементов.

## Операции с массивами
- Вывод массива
- Создание пустого изменяемого массива
- Ввод элементов с консоли
- Подсчёт количества элементов
- Добавление элемента
- Вставка элемента по индексу
- Удаление последнего элемента
- Удаление элемента по индексу
- Удаление всех элементов

## Структура (КИС)
- `ArrayProcessor.h` — интерфейс класса
- `ArrayProcessor.m` — реализация (приватные и публичные методы)
- `main.m` — создание экземпляра и вызов метода
